# Website

Next.js + Tailwind CSS. Run it from the project root with `npm run dev:web` and open
http://localhost:3000. See the root README for full setup.

- `src/app/` holds pages. Each folder is a URL: `login/` is `/login`, `activities/[id]/` is `/activities/123`.
- `src/lib/` holds the API client and login state.
- `src/components/` holds the navbar, route map and stat blocks.
